# 布料裁片排样系统

面向小型服装工作室的布料裁片排样（Nesting）Web 应用。输入布幅尺寸、矩形瑕疵区与裁片多边形轮廓后，系统自动计算每件裁片的位置与方向，给出实际占用长度；支持手动调整、锁定裁片并重新优化未锁定部分。

## 功能

- **排样优化**：在布幅宽度 × 可用长度内自动排入全部裁片，尽量缩短实际占用长度
- **裁片**：简单多边形轮廓（整数毫米顶点）、件数、可选是否允许旋转 180°；禁旋转件始终保持原方向
- **瑕疵区**：矩形，裁片自动避开；瑕疵区始终固定
- **约束保证**：裁片完整落在布幅内；裁片之间、裁片与瑕疵区之间无内部重叠（边界接触允许）
- **手动调整**：画布上拖拽移动裁片，或输入精确坐标；可旋转、锁定；冲突时指出冲突对象并保留原方案
- **锁定重优化**：锁定件与瑕疵区始终固定，仅重新排布未锁定裁片
- **部分方案**：无法排入全部裁片时明确列出未排入者，状态标记为「部分方案」，绝不标为完成
- **输入校验**：非法轮廓（自交、退化、非整数坐标）、非法尺寸在创建时即指出具体对象并拒绝

## 技术栈

- 后端：Node.js + Express，SQLite（better-sqlite3，WAL 模式）
- 前端：原生 HTML/Canvas/JS，无构建步骤
- 排样：1mm 占用栅格 + 左下启发式 + 接触周长优化 + 压实局部搜索；手动移动采用精确几何判定

## 快速开始

### 方式一：Docker Compose（推荐，一键启动）

```bash
docker compose up --build
```

启动后访问 **http://localhost:3000**

### 方式二：本地运行

```bash
npm install
npm start
```

访问 **http://localhost:3000**

### 运行测试

```bash
npm test        # 几何精确性与排样不变量共 24 项测试
```

## 使用流程

1. 左侧「新建排样方案」：填写布幅宽度、可用长度（整数 mm），添加瑕疵区（x, y, 宽, 高）与裁片型号（名称、顶点、件数、是否允许旋转 180°）。顶点每行一个 `x,y`。可点「填入示例」快速体验。
2. 点击「创建方案」——非法输入会逐条指出问题对象。
3. 点击「优化排样」——画布显示排样结果：红色为瑕疵区，绿色虚线为实际占用长度，🔒 为锁定件。
4. 拖动裁片手动微调（锁定件需先解锁）；或在左侧输入精确坐标、旋转角度后「应用位置」。冲突移动会被拒绝并列出冲突对象，原方案不变。
5. 勾选「锁定」后再次「优化排样」，仅重排未锁定裁片。
6. 顶部状态徽标：草稿 / 部分方案（列出未排入裁片）/ 完整方案。

## API 一览

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET | `/api/jobs` | 方案列表 |
| POST | `/api/jobs` | 创建方案（校验失败返回 400 + 逐项原因） |
| GET | `/api/jobs/:id` | 方案完整状态 |
| DELETE | `/api/jobs/:id` | 删除方案 |
| POST | `/api/jobs/:id/optimize` | 优化排样（仅未锁定件） |
| POST | `/api/jobs/:id/placements/:pid/move` | 移动/旋转/手动排入（冲突返回 409 + 冲突对象，原方案不变） |
| POST | `/api/jobs/:id/placements/:pid/lock` | 锁定/解锁 `{locked: bool}` |
| POST | `/api/jobs/:id/placements/:pid/unplace` | 移回未排区 |

## 规则与算法说明

- 坐标与尺寸一律为**整数毫米**；旋转仅支持 0°/180°（旋转不改变外接矩形尺寸）。
- 自动排样在 1mm 占用栅格上进行：栅格判定是保守的（宁可留缝也不重叠），因此结果**保证**无内部重叠、不压瑕疵、不出布幅；斜边附近可能留约 1mm 空隙，属正常排样余量。
- 手动移动使用精确几何判定，**边界接触（共点/共边）完全允许**。
- 优化目标：先排入全部裁片，再尽量缩短实际占用长度（面积降序 + 左下法则 + 接触周长平局裁决 + 压实局部搜索）。
- 规模上限（可在 `src/validate.js` 调整）：布幅 ≤ 5000mm，长度 ≤ 100000mm，布幅面积 ≤ 1.5 亿 mm²，裁片总数 ≤ 1000 件，单型号顶点 ≤ 200 个。

## 项目结构

```
src/geom.js      精确几何：轮廓校验、内部重叠判定（边界接触允许）
src/nest.js      排样优化器：栅格掩码、左下放置、压实搜索
src/validate.js  创建输入校验（逐项指明问题对象）
src/db.js        SQLite 模式与连接
src/server.js    Express 路由
public/          单页前端（画布、拖拽、表单）
test/run.js      24 项几何与排样测试
```
