# 布料裁片排样 Web 应用（Fabric Marker Studio）

面向小型服装工作室的布料裁片排样工具：在矩形布料（给定布幅宽度、可用长度、矩形瑕疵区）上，
自动排布若干**简单多边形裁片**，给出每件裁片的位置、方向（原方向 / 旋转 180°）与实际占用长度。
支持在浏览器画布上手动拖拽、数值移动、旋转与**锁定**，再只对未锁定裁片重新优化。

- 后端：Node.js + Express
- 数据库：SQLite（`better-sqlite3`，数据文件持久化；首次启动自动建表并写入示例数据）
- 前端：原生浏览器 Canvas，零构建

## 排样规则

- 所有坐标与尺寸均为**整数毫米**。
- 裁片必须**完整落在布幅**内。
- 裁片之间、裁片与瑕疵区**不得有内部重叠**；边/点**边界接触允许**（基于精确多边形裁剪求重叠面积判定，凹多边形同样准确）。
- 禁止旋转的裁片始终保持原方向；允许旋转的裁片可取 0° 或 180°。
- 优化目标：在满足约束的前提下尽量缩短**实际占用长度**（bottom-left 解析滑动启发式，多种排序取优）。
- 锁定裁片与瑕疵区在重新优化时始终固定，其余裁片围绕它们重新排布。
- **无法排入全部裁片时，明确列出每件未放入者，且不会把部分结果标记为完成方案**。
- 非法轮廓（自交、退化、非整数顶点等）、非法尺寸、或手动移动造成越界/重叠时，返回错误并**指出具体对象，现有方案保持不变**。

## 一键启动（Docker Compose，推荐）

```bash
docker compose up --build -d
```

启动后打开浏览器：

> **http://localhost:3000**

停止：

```bash
docker compose down          # 保留排样数据（命名卷 marker-data）
docker compose down -v       # 同时删除数据卷，恢复初始示例
```

## 直接用 Node 启动

需要 Node.js ≥ 18（推荐 20）。

```bash
npm install
npm start
```

同样访问 http://localhost:3000 。首次启动自动在 `./data/marker.db` 建表并写入示例数据。

运行内置几何/排样测试：

```bash
npm test
```

## 配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 监听端口（Compose 可用宿主机 `PORT` 映射，见下） |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DB_PATH` | `./data/marker.db`（容器内 `/app/data/marker.db`） | SQLite 数据库文件路径 |

Compose 方式修改宿主机映射端口，例如改用 8080：

```bash
PORT=8080 docker compose up --build -d
# 浏览器访问 http://localhost:8080
```

或直接编辑 `docker-compose.yml` 的 `ports`（如 `"8080:3000"`）。

数据持久化：Compose 使用命名卷 `marker-data`；裸 Node 运行时数据在项目 `data/` 目录。

## 使用说明

1. 左侧设置**布幅宽度 / 可用长度**并保存。
2. 添加**矩形瑕疵区**（左下角坐标 x,y 与宽高）。
3. 维护**裁片清单**：名称、多边形顶点（每行一个 `x,y`，按顺时针或逆时针顺序）、件数、是否允许旋转 180°。轮廓非法时会提示具体原因。
4. 点击 **▶ 重新优化排样**。右侧画布显示排样结果，绿色虚线标注**实际占用长度**。
5. 在画布上**点选**裁片：
   - 直接**拖拽**到整数毫米位置（松手时服务端校验；若与布边/瑕疵/其他裁片冲突则拒绝并弹回原位）；
   - 或在底部栏输入 X/Y 精确移动；
   - 允许旋转者可点“旋转 180°”；
   - 点“🔒 锁定”后该裁片固定，再点重新优化不会移动它。
6. 若有裁片排不下，顶部与左侧会以红色列出**未放入裁片及原因**，当前结果明确标记为**未完成的部分结果**。

## HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 布料配置、瑕疵、裁片、放置与最近一次优化结果 |
| PUT | `/api/config` | 修改布幅宽/长（与现有方案冲突则 409 拒绝） |
| POST/DELETE | `/api/defects[/:id]` | 新增 / 删除瑕疵区 |
| POST/PUT/DELETE | `/api/pieces[/:id]` | 新增 / 修改 / 删除裁片模板 |
| POST | `/api/placements/move` | 手动移动或旋转单件（冲突 409，指出冲突对象） |
| POST | `/api/placements/lock` | 锁定 / 解锁单件 |
| POST | `/api/optimize` | 锁定件与瑕疵固定，重新优化未锁定裁片 |

冲突响应形如：

```json
{
  "error": "存在冲突，未改动现有方案",
  "conflicts": [
    { "object": "前片 #3", "reason": "移动后与瑕疵区 #1 内部重叠" }
  ]
}
```

## 目录结构

```
server/
  geometry.js   # 整数坐标多边形：合法性、三角化、精确重叠面积、180° 旋转
  nesting.js    # bottom-left 排样引擎（锚点 + 解析滑动 + 整数取整）
  db.js         # SQLite 建表/初始化/读写
  server.js     # Express 静态服务与 JSON API、输入校验与冲突检测
public/
  index.html / style.css / app.js   # 画布页面
tests/
  geometry.test.js
Dockerfile / docker-compose.yml
```

## 初始示例数据

- 布幅 1500 × 8000 mm；
- 一个矩形瑕疵区；
- 前片 4 件、口袋 6 件（可旋转）、L 形袖片 3 件（禁旋转，凹多边形）。
